# 🎅 სეკრეტ სანტა

უფასო, მობილურზე მორგებული საიდუმლო სანტას თამაში — მეგობრებისთვის, კოლეგებისთვის და კლასელებისთვის.

**სტეკი:** Netlify (ჰოსტინგი + Functions) · Supabase (PostgreSQL) · ფრეიმვორკის გარეშე JS

## ფუნქციები
- ჯგუფის შექმნა: სახელი, იკონა (ემოჯი ან სურათი), მოთამაშეთა ლიმიტი, ბიუჯეტი, გათამაშების დრო
- მოწვევა ბმულით (`/j/კოდი`) ან კოდით; საკუთარი მოსაწვევი კოდის დაყენება
- ადმინს შეუძლია მოთამაშის გაგდება, გათამაშება ახლავე, გათამაშების გაუქმება, ჯგუფის წაშლა
- ავტომატური გათამაშება დათქმულ დროს (ყოველ 10 წუთში + გვერდის გახსნისას)
- პროფილი: სახელი, სურათი, ინტერესები; შესვლა სახელით + 4/6-ნიშნა PIN-ით, „დამიმახსოვრე"
- PIN-ის 5 არასწორი მცდელობის შემდეგ — 10 წუთიანი ბლოკი

## დაყენება
1. **Supabase:** შექმენით პროექტი → SQL Editor → ჩასვით `db/schema.sql` → Run.
   შემდეგ Connect → **Transaction pooler** → დააკოპირეთ URI (პაროლით).
2. **Netlify:** Add new site → Import from GitHub → ეს რეპო.
   Site configuration → Environment variables → `DATABASE_URL` = Supabase-ის URI. Deploy.

## ფონტები
ჩააგდეთ ფაილები `public/fonts/`-ში: `main.woff2`, `main-bold.woff2`, `display.woff2` (დეტალები: `public/css/fonts.css`).

## ლოკალური გაშვება
```
npm install
DATABASE_URL=postgres://... node dev-server.mjs
```
